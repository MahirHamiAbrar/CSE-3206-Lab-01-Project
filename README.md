# CSE-3206-Lab-01-Project

## Setup

### 1. Clone this repo

```bash
git clone https://github.com/MahirHamiAbrar/CSE-3206-Lab-01-Project.git
```

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

### 3. Download dataset

```bash
python download_dataset.py
```

### 4. Run

```bash
python weather_analysis.py
```
